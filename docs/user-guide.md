# User guide

For the current desktop application, use [the macOS guide](macos-app.md). It covers installation, tasks/projects, Today, subtasks, focus, native shortcuts, and backups.

## Getting into flow

Capture the work first. Choose a few items for today, use Focus on the next task, and finish with a useful next step. The journal keeps reflections and elapsed focus time. Completing a task is a separate, deliberate action.

Choose a landscape for the mood you want. Sound starts off and requires explicit opt-in. Immersive view hides surrounding content; Escape returns to the workspace. Preferences set your name, work mode, and gentler motion.

## Earlier web prototype

The hosted prototype's notes and sessions are browser-local. Its journal exports JSON. To migrate, export there and choose File → Import Backup in the desktop app. Import replaces the desktop studio after confirmation; export the desktop state first if you need to keep it.

The desktop and hosted web prototype do not synchronize automatically.
