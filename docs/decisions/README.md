# Architecture and product decision records

Current: [0002 — Standalone macOS application](0002-macos-desktop.md). The earlier [0001 browser-local decision](0001-platform.md) describes the initial prototype.

Create a numbered record when a consequential decision is resolved, for example `0001-platform.md`. Update a superseded decision's status and link its replacement.

## Record template

```markdown
# NNNN — Decision title

Date: YYYY-MM-DD (Asia/Jakarta)
Status: proposed | accepted | superseded

## Context
Concrete user need, constraints, and evidence.

## Options
Viable alternatives and their relevant tradeoffs.

## Decision
Selected option and the reasons it fits the need.

## Consequences
Implementation impact, limitations, and follow-up work.

## Verification
How the decision will be checked and any available evidence.
```
